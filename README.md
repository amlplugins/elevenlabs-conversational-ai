# @amlplugins/elevenlabs-conversational-ai

Native `@elevenlabs/elevenlabs-js` SDK re-exported under the `@amlplugins` namespace.

> ElevenLabs Conversational AI — agents with TTS+STT+LLM pipelines, WebSocket voice loop, tools, knowledge bases.

## Install

```bash
npm install @amlplugins/elevenlabs-conversational-ai
```

## Use

```ts
import { /* named exports from @elevenlabs/elevenlabs-js */ } from "@amlplugins/elevenlabs-conversational-ai";
// or
import sdk from "@amlplugins/elevenlabs-conversational-ai";
```

Built and published by GitHub Actions on every push to `main`.

Part of the amlplugins family — see https://github.com/amlplugins.
